How GitHub bots review Atelier pull requests

via Tether
  1. 1Open a pull request hereTurn on “Review on GitHub” for the repository.
  2. 2Tether mirrors itThe branch goes to your private GitHub twin and a matching PR opens there.
  3. 3Bots review on GitHubCodeRabbit, Cursor Bugbot or any GitHub App you’ve installed on the twin.
  4. 4Comments sync backThey appear on the Atelier PR with a “via Tether” chip. Merging here closes the mirror.

Privacy: your code goes to the bots’ servers via GitHub. You need your own account with each bot service, and only repositories you switch on are mirrored.
