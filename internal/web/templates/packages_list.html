Other registries

Container Log in with any username and a token as the password:

docker login {{$d.RegistryHost}}
docker push {{$d.RegistryHost}}/{{(index $d.Owners 0).Name}}/app:latest
{{if not $d.HTTPS}}

Docker only talks to registries over HTTPS. Serve Atelier through nginx with TLS, or add "{{$d.RegistryHost}}" to insecure-registries in Docker's daemon.json.

{{else}}

In Portainer, add {{$d.RegistryHost}} under Registries → Custom registry with the same token.

{{end}}
