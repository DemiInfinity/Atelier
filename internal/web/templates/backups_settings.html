Restoring

Restore runs from the server's shell with the atelier restore command. Nothing is deleted: whatever it replaces is moved aside to pre-restore-<time>.

One repository (Atelier can keep running):

docker exec -it atelier atelier restore /backups/atelier-…tar.gz --repo owner/name

Everything (database and all repositories). Stop Atelier first; restore refuses while the server is running unless you pass --force:

docker stop atelier
docker run --rm -v atelier-data:/data -v atelier-backups:/backups atelier:latest \
  restore /backups/atelier-…tar.gz
docker start atelier

Portainer prefixes volume names with the stack name; docker volume ls shows the real ones. To restore on a new server, copy a snapshot there, run the same command, then start Atelier. atelier backup takes a snapshot from the shell, which is handy before upgrades.
