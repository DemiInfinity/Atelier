Lockfile workflow

Add this as .atelier/workflows/lockfiles.yml. It runs on update branches only, and the job token may push nothing but lockfiles to the branch it runs on.

on:
  push:
    branches: ["atelier-updates/**"]
jobs:
  lockfiles:
    runs-on: [self-hosted]
    steps:
      - uses: actions/checkout@v4
      - uses: atelier/update-lockfiles@v1
