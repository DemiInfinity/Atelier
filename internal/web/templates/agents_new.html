Agent Add an agent

An agent is a Markdown workflow: YAML front matter says when it runs and which tools it may use, and the text below it is the task. Copy a template into .atelier/workflows/ and commit it. Nothing here commits for you.

Before the first run

  1. Add your Anthropic API key as the secret {{$d.Secret}} (repository or account secrets), or name another secret with secret:.
  2. Make sure a runner is online. Agents run on self-hosted by default and only need network access to this server and the Claude API.
  3. The first run waits for your approval, and so does every run after its tools: list changes or for a pull request someone else opened.

Front matter: on, engine: claude, model (default {{$d.Model}}), effort (low, medium, high, xhigh, max), tools, runs-on, max-turns (≤ 100), max-tokens (≤ 2M), timeout-minutes, secret. Triggers: push, pull_request, schedule, workflow_dispatch, and issues (opened, labeled).
