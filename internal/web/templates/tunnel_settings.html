Cloudflare Tunnel
Named tunnel
  1. In Cloudflare Zero Trust, open Networks → Tunnels and create a tunnel (cloudflared).
  2. Copy the token from the install command (the long value after --token) and paste it below.
  3. Add a public hostname (e.g. git.example.com) with service type HTTP and URL {{$d.Listen}}. Not port 3000: requests there skip every remote-access rule, so Atelier refuses them.
{{if $c.HasToken}}{{end}}

Tailscale

Either way, signing in to Atelier still takes a passkey (or a token for git and APIs). Being on your tailnet never signs you in.

{{else}}
  1. In the Tailscale admin console, open DNS: turn on MagicDNS and press Enable HTTPS.
  2. For Public: open Access controls and give this machine the funnel node attribute.
  3. Open Settings → Keys, generate an auth key (one-off, not ephemeral) and paste it below.
{{end}}
